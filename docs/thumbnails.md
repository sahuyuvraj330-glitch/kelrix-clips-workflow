# Thumbnails

A thumbnail must match the video it belongs to — same style, same world.

## The style rule

Anchor every thumbnail to an actual frame from the finished video (or the QC sheet, before the render). Copy the video's cutout style exactly:

- Simple flat 2D cutout characters
- Small round heads, dot eyes, simple line mouths
- Jointed limbs with visible circle joints
- Flat solid colours, thin dark outlines
- Cream label boxes with dark text

**Never:** clay texture, paper texture, detailed realistic cartoon faces, or big-head chibi proportions. The figure is a tall slim cutout with a small round head.

Check each option against the reference frame before showing it, and drop any option whose style doesn't match.

## The curiosity test

Every thumbnail must pass all three:

1. **The subject is doing something** — mid-action, never standing alone with nothing happening.
2. **The image symbolises the story** — the picture means something without the title.
3. **It leaves the viewer wondering what happens next.**

Drop any option that fails one part, even when its style is right. Name the test result for each option when presenting a batch.

## Fresh designs, varied backgrounds

- Thumbnails are fresh standalone designs of our own — not cropped video scenes. (Scene-based thumbnails only when the owner asks for one.)
- Each batch gets its own distinct, scene-specific background. Don't reuse the same background across options.

## Presenting a batch

- Show a small numbered batch of actual images, not text descriptions of concepts.
- Give a real recommendation with a reason when asked.
- Stop expanding the batch when more options don't fix a style or story miss — fix the style or the story instead.

## After upload

After the thumbnail is set in YouTube Studio, reload the video page fully and check the chosen thumbnail is still applied. Re-upload it if it reverted during scheduling, then reload again. The upload isn't done until the reload check passes.
